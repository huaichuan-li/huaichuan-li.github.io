语音大模型算法实习生 · 基础模型中心Speech LLM Algorithm Intern · Foundation Model Center

2025.10 – 2026.02

VoxCPM 1.0 → 2.0 架构迭代Architecture Iteration

参与 GitHub 37k+ Stars 开源语音大模型从 1.0 到 2.0 的迭代训练，参与四项核心架构改进：AudioVAE V2 非对称编解码（16kHz 编码 / 48kHz 重建，隐式超分辨率）；RALM 融合改造（Concat-Proj 融合层、移除位置编码、FSQ 瓶颈拓宽）；LocDiT 多 Token 条件化（提升扩散一致性）；统一序列组织（基础 TTS / 声纹设计 / 可控克隆 / 续写克隆四种模式共享参数）。Contributed to the 1.0 → 2.0 iteration of a 37k+ star open-source speech LLM, touching four core architecture upgrades: AudioVAE V2 asymmetric codec (16kHz encode / 48kHz reconstruct, implicit super-resolution); RALM fusion rework (Concat-Proj, position-encoding removal, wider FSQ bottleneck); LocDiT multi-token conditioning for diffusion consistency; unified sequence organization shared across four TTS modes.

多语种 ASR 评测 · 数据工程 · 风洞实验Multilingual ASR Eval · Data Engineering

构建覆盖 10 种方言 + 20 种国际语言的 ASR 评测体系，对 Whisper、Qwen3-ASR 等 8 个主流模型系统评测；搭建风洞实验框架，以控制变量法调整方言/通用、近场/远场、纯净/带噪样本配比，分析对 WER/CER 与噪声鲁棒性的影响；搜集处理 2 万小时噪声数据，设计在线增强方案并经消融验证抗噪提升。Built an eval suite spanning 10 dialects + 20 languages across 8 mainstream ASR models; ran wind-tunnel experiments on dialect/proximity/noise data ratios against WER/CER and noise robustness; processed 20k hours of noise data with online augmentation validated by ablations.

语音分离与全双工对话系统Speech Separation & Full-Duplex System

评测 Mel-Band-Roformer、Demucs、SAM-Audio 在 -5dB~20dB SNR 下的分离性能（STOI/PESQ/RTF），将 Roformer 重采样移植至 GPU CUDA 提速推理；部署 FireRedChat 全双工语音对话系统，集成 pVAD、流式 ASR、语义理解、LLM、TTS 端到端模块，实现实时打断与流式传输。Evaluated Mel-Band-Roformer, Demucs and SAM-Audio at -5~20dB SNR (STOI/PESQ/RTF), moving Roformer resampling to GPU CUDA for faster inference; deployed the FireRedChat full-duplex voice stack — pVAD, streaming ASR, semantic understanding, LLM and TTS — with realtime barge-in and streaming transport.
